# 原型消费与跨域同步

视觉技能独立维护策略、设计变量、组件和主题；交互技能的完整可操作原型应用这些规范。没有适用规范时原型采用极简线框，有规范时不能以“交互与视觉分离”为由忽略规范。

更新既有项目时同时核对 CONVENTIONS；仅同步与已授权变更冲突的旧条款，保留项目特有约束，不覆盖整份规范。

## 输入与输出

输入包括原型引用的规范版本、缺少的组件/状态、已确认设计依据。判断是已有规范可覆盖、规范投影补充，还是需要探索的新方向。输出具体规范路径、主题、变更及受影响原型，不替交互技能决定业务行为。

## 消费约定

- 可提供从设计变量/主题到 CSS 变量的可重复映射；记录来源和生成/读取方式。映射不成为第二份手工维护的数值事实。
- 不把页面专属布局强行变成全局组件规则。组件规范保留语义、变体、尺寸、状态与 `token_refs`。
- 业务页面视觉验证使用交互域的正式或候选原型；视觉域的样式预览负责系统组件及主题预览。

## 变更检查

1. 读取索引和已有关系，查找消费该规范的原型和映射。
2. 同步本域的视觉简报、设计变量、组件、主题和预览；记录破坏性设计变量改名、状态和尺寸变化。
3. 回传受影响交互路径、重建映射方法和需要检查的布局/状态。跨域写入由具备授权的智能体明确接续，不隐式导入或调用其他技能。
4. 未完成原型更新时列出待同步项；候选依赖旧基线时标记过时或提出重基线需求，不能静默改变对比条件。


交接不构成强制阶段或人工等待。同一智能体可在当前授权和选定缺口内显式使用交互技能完成同一结论的原型同步；新发现的独立取舍回传智能体决定。仅缺少同步动作不能被描述为新的审美批准需求。
